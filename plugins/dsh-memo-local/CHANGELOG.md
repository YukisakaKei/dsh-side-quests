# Changelog

## 0.1.2 - 2026-10-27

- 包名改为 `dsh-memo-local`，避免与 npm 上的同名第三方插件混淆；功能与存储键不变。

## 0.1.1 - 2026-10-20

- 通知去掉标题，只保留正文。
- 正文逐行列出全部未完成事项，不再限制条数，也不再追加剩余数量。

## 0.1.0 - 2026-10-20

- 首次实现：全局面板维护与对话无关的单行待办清单。
- 每天在 09:30–11:30、14:00–17:30 的整点/半点弹出静音 Windows 通知；
  09:00、12:00、13:30、18:00 不提醒。
- 通知列出最多 5 条未完成事项；没有未完成项时显示「暂无待办」。
- 点击通知聚焦 DSH 并打开备忘面板。
- 备忘数据保存在 localStorage；Desktop 落盘到 profile 的 `desktop-storage.json`。
- 面板支持添加、编辑、勾选完成、删除、暂停提醒和测试通知。
- 迟到超过 2 分钟的提醒跳过；同一提醒点去重。
