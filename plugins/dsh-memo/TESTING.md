## 手工验收清单

### 面板与数据

- [ ] 侧栏出现「备忘」入口，点击打开全局面板，不改变当前会话。
- [ ] 输入一条待办按 Enter 添加；空内容不添加。
- [ ] 勾选后条目前移/沉底并显示删除线；再次勾选恢复。
- [ ] 点击编辑按钮修改文本，Enter 或失焦保存，Escape 取消。
- [ ] 删除按钮移除条目。
- [ ] 重启 DSH 后备忘仍在。
- [ ] 切换 profile 后看到另一份库（数据随 profile 隔离）。

### 提醒

- [ ] 面板里的「测试通知」立即弹出一条静音 Windows 通知。
- [ ] 空清单时测试通知正文为「暂无待办」；全部完成时同样。
- [ ] 超过 5 条未完成时，正文显示前 5 条并追加「还有 N 项」。
- [ ] 点击通知后 DSH 窗口恢复/聚焦，并打开备忘面板。
- [ ] 关闭「启用提醒」后，到点不弹通知；「测试通知」仍可用。
- [ ] 重新打开「启用提醒」后，下一个提醒点恢复弹出。
- [ ] 把窗口隐藏到托盘，等待一个提醒点，通知仍然出现。
- [ ] 通知没有声音（`silent: true`）。
- [ ] 在 09:00、12:00、13:30、18:00 不弹提醒。
- [ ] 在 09:30、11:30、14:00、17:30 正常弹出。
- [ ] 提醒标题中的时间与目标提醒点一致（例如 09:30）。
- [ ] 连续两个提醒点之间只弹一次，不重复。

### 异常与边界

| 用例 | 关注点 |
|---|---|
| 空清单 | 正文为「暂无待办」，不跳过提醒 |
| 全部已完成 | 同上 |
| 6 条以上未完成 | 只列 5 条，并显示剩余数量 |
| 极长单行文本 | 通知中截断，面板中完整显示 |
| 系统睡眠跨过提醒点 | 唤醒后不补报 |
| 通知迟到超过 2 分钟 | 跳过该次提醒 |
| Windows 专注助手开启 | 通知可能被系统拦截，插件不重试 |
| DSH 完全退出 | 不提醒 |
| 多个 DSH 窗口 | 可能各弹一次；关闭多余窗口后恢复单次 |

## 时间点核对

自动化测试覆盖了调度边界；手工核对真实时钟时，建议选择以下相邻时段：

1. 09:29 前把窗口隐藏到托盘，确认 09:30 弹出。
2. 11:59 前保持窗口打开，确认 12:00 不弹。
3. 13:29 前保持窗口打开，确认 13:30 不弹，14:00 弹出。
4. 17:59 前保持窗口打开，确认 18:00 不弹。

提醒内容可以在等待期间用「测试通知」单独验证，避免每次都等到整点。
