# dsh-tcl-copy 测试

自动测试命令与通用测试数据规则见 [docs/testing.md](../../docs/testing.md)。
安装与生效条件见 [docs/local-install.md](../../docs/local-install.md)。

本文只记录本插件的手工验收与边界用例；行为、限制和宿主兼容不在本文重复。

## 手工验收清单

- [ ] `.tcl` 预览头部与内置代码预览一致：左侧「代码块」，右侧复制图标。
- [ ] 悬停复制图标显示「复制全文」，点击后剪贴板内容与文件全文一致，含末尾换行与 CRLF。
- [ ] 点击后头部显示「正在读取…」，完成后图标变为对勾并提示「已复制」，约 1 秒后恢复。
- [ ] 空文件复制得到空串。
- [ ] 超过宿主上限的文件提示「文件过大，无法复制全文」，不复制部分内容。
- [ ] 含 NUL 字节的文件提示「疑似二进制文件，无法复制」。
- [ ] 读取失败提示「读取失败」，可再次点击重试。
- [ ] UTF-8 BOM / UTF-16 BOM 文件复制后无 BOM 残留、内容完整。
- [ ] 换行开关可切换，显示正常。
- [ ] 大文件（加载文本 ≥ 2 MiB）关闭行号但复制仍完整。
- [ ] 渲染器下拉中本插件为首选，「文本」兜底仍可选。
- [ ] 打开 `.py` / `.v` / `.sv` / `.md`：行为与未装插件时一致。
- [ ] 卸载或禁用插件后，`.tcl` 回到内置纯文本预览。
- [ ] 中文注释显示与复制正常；GBK 等非 UTF-8 文件表现为乱码提示（已知限制）。

## 边界用例

| 用例 | 关注点 |
|---|---|
| 0 字节文件 | 头部仍在，复制空串 |
| 单行且无结尾换行 | 不丢字符 |
| 10 万行 | 是否卡顿；行号是否关闭 |
| CRLF / LF 混合 | 复制是否原样保留 |
| 名为 `.tcl` 的二进制 | 是否提示二进制而不是白屏 |
| 极长单行 | 软换行关闭时横向滚动是否正常 |
| 文件被外部修改 | 内置刷新是否仍工作 |

## 剪贴板核对

Windows 可用 PowerShell 读取剪贴板后与源文件比较：

```powershell
Get-Clipboard -Raw
```

对比时注意：复制结果保留末尾换行；部分编辑器保存时可能自动补齐或删除末尾换行，
应以字节级比较为准。
