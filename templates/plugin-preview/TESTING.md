# __PLUGIN_NAME__ 测试

自动测试命令与通用测试数据规则见 [docs/testing.md](../../docs/testing.md)。
安装与生效条件见 [docs/local-install.md](../../docs/local-install.md)。

本文只记录本插件的手工验收与边界用例。

## 手工验收清单

- [ ] 目标后缀的预览出现本插件渲染器，且为渲染器下拉中的首选。
- [ ] 复制控件可用，复制结果符合 README 的行为描述。
- [ ] 换行开关可切换，显示正常。
- [ ] 其它后缀的预览行为与未装插件时一致。
- [ ] 禁用或卸载插件后，目标后缀回到内置预览。

## 边界用例

| 用例 | 关注点 |
|---|---|
| 0 字节文件 | 是否仍能正常渲染与复制 |
| 单行且无结尾换行 | 是否丢字符 |
| 大文件 | 是否卡顿；行号策略是否生效 |
| 非 UTF-8 编码 | 是否按 README 描述处理 |
